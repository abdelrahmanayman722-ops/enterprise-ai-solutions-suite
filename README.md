### R1: Startup & Remote Contract Hunter (`contract_hunter/`)
A resilient, multi-feed extraction and opportunity intelligence engine that autonomously aggregates, standardizes, filters, and generates tailored bids for high-paying roles.

* **Multi-Source Ingestion Adapters**:
  - `adapters/hn_adapter.py`: Connects to Hacker News Algolia REST API to discover the latest monthly *"Who is hiring?"* threads, isolating top-level postings (`parent_id == story_id`), while streaming live YC startup posts via the Firebase REST API.
  - `adapters/wwr_adapter.py`: Ingests and parses live RSS feeds across Full-Stack, Programming, Backend, and DevOps categories from WeWorkRemotely.
  - `adapters/yc_adapter.py`: Scrapes and extracts pre-hydrated startup job listings from `ycombinator.com/jobs` via Inertia.js data attributes.
  - `adapters/remoteok_adapter.py`: Resilient client pulling high-paying roles from the RemoteOK public API.
* **Multi-Currency Normalizer (`normalizer.py`)**:
  - Standardizes hourly, monthly, and annual compensation formats into normalized monthly USD equivalents.
  - Filters strictly for high-ticket opportunities ($\ge \$3,500/\text{month}$).
  - Automatically tags tech competencies (`next.js`, `react`, `node.js`, `python`, `ai`, `sql`, `typescript`, `fastapi`).
  - Infers funding rounds (YC Cohorts W24/S23, Seed, Series A/B).
  - Calculates deterministic Match Scores ($0 - 100$).
* **Tailored Pitch Generator (`pitch_generator.py`)**:
  - **CTO Pitch**: Emphasizes architecture purity, concurrency, zero technical debt, performance benchmarks, and type-safety.
  - **Founder Pitch**: Emphasizes shipping speed, business metrics, ROI, conversion rates, and MVP delivery within days.
  - **Dynamic Proof Injection**: Injects specific achievements based on detected technical tags.
* **3-Tier Fallback Hierarchy (`cache_manager.py`)**:
  - **Tier 1 (Live Network)** $\rightarrow$ **Tier 2 (Disk Cache with TTL)** $\rightarrow$ **Tier 3 (Emergency Curated High-Ticket Fallback)** ensuring zero operational downtime.

### R2: Enterprise AI & Automation Suite (`ai_solutions_suite/`)
Three standalone, production-ready software solutions engineered for direct B2B sales ($1,500 – $4,000 per implementation + recurring monthly retainers):

#### 1. Enterprise AI Agent & RAG (`ai_agent_rag/`)
* **Dynamic Relational Introspector (`schema_introspector.py`)**: Automatically inspects SQLite and PostgreSQL schemas, extracting table structures, primary/foreign keys, and data types.
* **SafeSQLExecutor Barrier (`safe_sql_executor.py`)**: Strict security barrier combining Python AST analysis and regex pattern matching to ensure zero destructive mutations (`DROP`, `DELETE`, `UPDATE`, `INSERT`, `ALTER`, `TRUNCATE`, `ATTACH`). Enforces read-only `SELECT` queries with clamped row limits.
* **Hybrid Retriever (`hybrid_retriever.py`)**: Reciprocal Rank Fusion (RRF) combining sparse BM25 lexical ranking with dense vector semantic search.
* **Conversational Memory (`conversational_memory.py`)**: Sliding-window context buffer maintaining multi-turn dialogue coherence.
* **Autonomous Agent (`rag_agent.py`)**: CLI and programmatic interface returning structured responses with confidence scores and executed SQL telemetry.

#### 2. Resilient Python Web Scraper (`python_scraper_engine/`)
* **Anti-Detection Engine (`anti_detection.py`)**: Dynamic User-Agent pool matching modern Chromium/Firefox browsers with Client Hints (`Sec-CH-UA`, `Sec-Fetch-Site`, `Sec-Fetch-Mode`).
* **Token Bucket Rate Limiter (`rate_limiter.py`)**: Monotonic token bucket throttling per target domain, enforcing jitter to emulate genuine human browsing patterns.
* **Data Normalizer & Deduplicator (`normalizer.py`)**: Robust currency extraction, ISO date conversion, and SHA-256 fingerprinting for record deduplication.
* **Contract Validation & Storage Exporter (`storage_exporter.py`)**: Automated SQLite schema creation with atomic `UPSERT` capabilities, JSON lines, and CSV export.

#### 3. Executive SaaS Dashboard (`saas_dashboard/`)
* **Zero-Dependency Interactive Web App (`dashboard_app.html`)**: Beautiful, self-contained executive dashboard with dark-mode styling, real-time KPI counters, revenue charts, and active agent fleet monitoring.
* **Modular React Component Suite (`components/`)**: Next.js 15 / React 19 production components (`ExecutiveDashboard.tsx`, `TelemetryGrid.tsx`, `RevenueChart.tsx`, `AgentFleetTable.tsx`, `TransactionStream.tsx`).

### 1. Windows One-Click Launchers

#### Method A: Command Prompt Launcher (`run_cockpit.bat`)
Simply double-click `run_cockpit.bat` in Windows File Explorer, or run in CMD:
```cmd
run_cockpit.bat
```
* **What it does**: Automatically checks for Python, installs any missing dependencies from `requirements.txt`, opens your default browser directly to `http://127.0.0.1:8000`, and starts the FastAPI server.

#### Method B: PowerShell Launcher (`run_cockpit.ps1`)
Right-click `run_cockpit.ps1` and select **Run with PowerShell**, or execute:
```powershell
powershell -ExecutionPolicy Bypass -File .\run_cockpit.ps1
```
* **What it does**: Provides a colored executive console display, verifies the Python runtime and dependencies, launches the browser to `http://127.0.0.1:8000`, and handles graceful server shutdown.

## 📡 REST API Reference / مرجع واجهات برمجة التطبيقات

The Cockpit FastAPI backend provides a clean RESTful interface running on port 8000:

### 1. Health & Status
* **`GET /api/health`**
  - **Response**:
    ```json
    {
      "status": "healthy",
      "version": "1.0.0",
      "uptime_seconds": 124.5,
      "active_pipeline_count": 8,
      "timestamp": "2026-10-23T11:15:00Z"
    }
    ```

### 2. Opportunities Management
* **`GET /api/opportunities`**
  - **Query Parameters**:
    - `source` (string, optional): Filter by platform (`hacker_news`, `weworkremotely`, `yc`, `remoteok`).
    - `skill` (string, optional): Filter by tech tag (`next.js`, `python`, `ai`, etc.).
    - `min_salary` (float, optional): Filter by minimum monthly USD (defaults to 3500.0).
    - `search` (string, optional): Text query across title, company, and description.
  - **Response**: List of structured high-ticket opportunity records.

* **`POST /api/opportunities/sync`**
  - Reads `contract_hunter/curated_high_ticket_jobs.json`, syncs latest discoveries into Cockpit memory, and returns count of updated opportunities.

### 3. Pipeline & Kanban Management
* **`GET /api/pipeline`**
  - **Response**: Dictionary of deals categorized by stage (`leads`, `pitched`, `interviewing`, `contract_sent`, `won`, `closed`).

* **`POST /api/pipeline`**
  - **Request Body**:
    ```json
    {
      "opportunity_id": "hn_49922569_12",
      "title": "Lead Full-Stack AI Engineer",
      "company": "Nexus AI Labs",
      "stage": "leads",
      "monthly_value": 5500.0,
      "source": "Hacker News",
      "notes": "YC W24 startup looking for rapid MVP delivery"
    }
    ```
  - **Response**: Newly created deal with unique `id`, creation timestamp, and saved state.

* **`PUT /api/pipeline/{deal_id}`**
  - **Request Body**: Partial or full update payload (e.g., `{"stage": "interviewing"}`).
  - **Response**: Updated deal object.

* **`DELETE /api/pipeline/{deal_id}`**
  - **Response**: `{"status": "deleted", "id": "..."}`.
